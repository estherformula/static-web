QNA · 클로드 코드 첫 실행 가이드

클로드 코드를 처음 실행하면 뜨는 질문들, 뭐라고 답해야 하나요?

설치를 마치고 claude를 처음 입력하면 화면에 몇 가지 질문이 순서대로 나타납니다. 전부 뜻을 몰라도 사실 정답은 정해져 있어요. 하나씩 뭘 물어보는 건지, 뭘 눌러야 하는지, 그리고 "이 초기 설정을 꼭 다 해야 하는지"까지 정리했습니다.

🆕 최초 1회 실행 ⏱ 1분이면 끝 🧑‍💻 개발 지식 불필요

💡 이런 분을 위한 글이에요. 클로드 코드 설치는 끝냈는데, 처음 실행했더니 못 보던 화면(테마 선택, 터미널 설정, 로그인, "이 폴더를 믿나요?" 같은 질문)이 연달아 떠서 뭘 눌러야 할지 몰랐던 분. 결론부터 말하면 대부분 기본값(추천 옵션)을 그대로 선택하면 됩니다.

0 이 질문들은 언제, 왜 뜨나요?설치 프로그램이 컴퓨터에 클로드 코드를 깔아 놓은 것과, 그걸 "내 계정으로, 내 취향에 맞게" 처음 켜는 것은 별개의 단계예요.

터미널(PowerShell 등)에서 claude라고 입력하고 Enter를 누르면, 이번이 이 컴퓨터(또는 이 폴더)에서 처음 실행하는 것인지 확인한 뒤 아래 순서로 화면이 넘어갑니다.

  • 1
    화면 색상(테마) 고르기 — 눈에 편한 배색 선택
  • 2
    터미널 단축키 설정 제안 — 줄바꿈 등 편의 기능 자동 설정 여부
  • 3
    로그인 — 어떤 계정으로 쓸지 선택 후 브라우저 인증
  • 4
    "이 폴더를 신뢰하나요?" — 새 작업 폴더마다 한 번씩 확인

🖌 뭘 골라야 하나요?

터미널 창 배경이 검은색/어두운 색이면 다크 모드, 흰색/밝은 색이면 라이트 모드를 고르면 됩니다. 색을 구분하기 어렵다면 "색맹 배려" 버전을 선택하세요. 뭘 골라도 기능 차이는 없고 순수하게 눈에 편한 걸 고르는 것이라 정답은 없습니다.

나중에 마음이 바뀌면 대화창에 /theme라고 입력해서 언제든 바꿀 수 있어요. 지금 급하게 고민하지 않아도 됩니다.

⌨️ 이건 뭘 하는 건가요?

메시지를 입력하다가 줄을 바꾸고 싶을 때 Option(Alt)+Enter 같은 단축키가 바로 작동하게 해주고, 작업이 끝나면 화면이 살짝 깜빡여서 알려주는 등 편의 기능을 자동으로 켜주는 겁니다. 내 컴퓨터의 다른 설정을 건드리거나 위험한 작업이 아니라 "예"를 선택하는 걸 추천합니다.

"아니요"를 눌러도 문제는 없습니다 — 줄바꿈은 언제든 Ctrl+J를 누르거나 \를 입력한 뒤 Enter를 치면 되고, 나중에 /terminal-setup이라고 입력하면 이 설정을 다시 켤 수 있어요.

🔒 왜 이런 걸 물어보나요?

클로드 코드는 지금 열려 있는 폴더 안의 파일들을 읽고 그 내용을 참고해서 답합니다. 그런데 만약 그 폴더 안에 악의적으로 조작된 파일(예: 이상한 지시가 숨겨진 문서)이 있다면, AI가 그 내용에 속아 원치 않는 행동을 할 위험이 있어요. "이 폴더를 신뢰하나요?"는 내가 직접 만들었거나 출처가 확실한 폴더에서만 작업을 시작하라는 안전장치입니다.

내가 직접 만든 회사/개인 작업 폴더라면 그냥 "예"를 선택하면 됩니다. 반대로 이메일 첨부파일을 풀어놓은 폴더, 누가 준 압축파일을 그대로 연 폴더처럼 출처가 불분명한 경우엔 신뢰하기 전에 폴더 안 파일을 먼저 눈으로 확인하는 게 안전합니다.

⚠️
바탕화면이나 "내 문서" 최상위, 사용자 홈 폴더에서 바로 실행하면? 이 확인이 "이번 실행에서만" 유효하고 컴퓨터에 저장되지 않아, 실행할 때마다 매번 다시 뜹니다. 매번 묻지 않게 하려면 cd로 실제 작업용 하위 폴더(예: Documents\MyProject)로 이동한 뒤 claude를 실행하세요 — 그 폴더에 대한 신뢰는 저장되어 다음부터 다시 묻지 않습니다.

5 이건 첫 실행 질문이 아니에요 — "권한 승인" 팝업과 헷갈리지 마세요

위 4가지를 다 지나면 대화 화면이 나옵니다. 이후 실제로 클로드에게 "이 파일 고쳐줘", "이 명령어 실행해줘" 같은 작업을 시키면, 그때마다 "이 작업을 진행해도 될까요?" 같은 승인 팝업이 따로 뜹니다. 이건 초기 설정이 아니라 작업할 때마다 매번 확인하는 안전장치이니 별개로 이해하면 됩니다. 반복되는 작업이라면 "항상 허용" 옵션을 선택해 다음부터 묻지 않게 할 수도 있어요.

6 그래서, 초기 설정을 꼭 다 해야 하나요?

질문필수 여부이유
테마(색상) 선택 선택 필요하지만 부담 없음 화면에 표시는 되지만 아무거나 골라도 기능엔 영향 없음. /theme로 언제든 재설정 가능.
터미널 단축키 설정 건너뛰어도 무방 편의 기능일 뿐. "아니요"를 눌러도 클로드 코드는 정상 작동하며, /terminal-setup으로 나중에 켤 수 있음.
로그인 필수 로그인하지 않으면 클로드와 대화 자체가 불가능. 건너뛸 수 없음.
폴더 신뢰 확인 필수 보안 장치라 매 폴더 최초 1회는 반드시 답해야 다음 단계로 진행됨. "아니요"를 누르면 그 폴더에서는 작업을 시작하지 않음.
💡
결론적으로 실질적인 "필수"는 로그인과 폴더 신뢰 확인 2가지뿐이고, 나머지(테마·터미널 단축키)는 취향과 편의의 문제라 아무거나 골라도 나중에 얼마든지 바꿀 수 있습니다. 정답을 몰라서 헤맬 필요 없이, 기본으로 선택되어 있는 옵션 그대로 Enter를 눌러도 충분합니다.

✓ 결론

클로드 코드를 처음 켜면 테마 선택 → 터미널 설정 제안 → 로그인 → "이 폴더를 신뢰하나요?" 순으로 화면이 뜹니다. 테마와 터미널 설정은 편의 기능이라 아무거나 골라도(또는 건너뛰어도) 무방하고, 로그인과 폴더 신뢰 확인만 실제로 꼭 필요한 단계입니다. 헷갈리면 화면에 미리 선택되어 있는 옵션 그대로 Enter를 누르면 됩니다 — 전체 과정은 1분이 채 걸리지 않습니다.
