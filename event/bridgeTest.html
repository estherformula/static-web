이벤트 연동 테스트

이벤트 페이지 웹↔앱 연동 통로(estherpack) 테스트용 페이지입니다. 앱 웹뷰에서 열어야 동작합니다.
이 페이지 제목("이벤트 연동 테스트")이 앱 상단 바에 보이면 웹뷰 제목 표시도 정상입니다.

1. 연동 통로 감지

통로-
platform-
appVersion-

estherpackInfo 는 버튼을 누를 때 읽습니다(Android는 로드 직후 값이 없을 수 있음).

2. 쿠폰 다운로드 (downloadCoupon)

결과 알럿은 앱이 띄웁니다. 회신 내용은 아래 로그에 남습니다. 두 번째 시도에서 CP-409-03(이미 등록)이 와야 정상입니다.

3. 예외 케이스

모르는 action과 코드 없는 요청은 UNKNOWN_ACTION 으로 회신되어야 합니다.

4. 딥링크 버튼

영양제 조합하기 (스토어 홈, 웹뷰 닫힘) 문진하기 (닫으면 돌아옴) 상담하기 (닫으면 돌아옴)
