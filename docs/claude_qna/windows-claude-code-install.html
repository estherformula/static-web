QNA · 클로드 코드 설치 가이드

윈도우에서 클로드 코드(Claude Code) 설치하는 법

컴퓨터에 클로드 관련 프로그램이 하나도 없는 상태에서 시작합니다. PowerShell을 열고, 설치하고, 원하는 폴더로 이동해서, 처음으로 실행해보는 과정까지 순서대로 따라오시면 됩니다.

🪟 Windows 10 / 11 ⏱ 5분이면 충분 🧑‍💻 개발 지식 불필요

💡 이런 분을 위한 글이에요. "클로드 코드"라는 이름은 들어봤지만 컴퓨터를 켜서 어디서부터 눌러야 할지 모르는 분. 검은 화면(터미널)이 낯선 분. 이 글 순서대로만 따라 하면 설치부터 첫 대화까지 끝낼 수 있습니다.

0 시작 전에 확인할 것

아래 3가지만 확인되면 바로 시작할 수 있어요.

  • ✓
    Windows 10(2018년 10월 업데이트 이후 버전) 또는 Windows 11 — 최근 몇 년 안에 산 PC라면 대부분 해당됩니다.
  • ✓
    인터넷 연결 — 설치 파일을 내려받고 로그인할 때 필요해요.
  • ✓
    Claude 계정 (또는 Claude Pro/Max 구독) — 없다면 로그인 단계에서 claude.ai로 이동해 바로 만들 수 있습니다.
✅
Node.js 같은 프로그램은 미리 설치할 필요가 없습니다. 예전에는 개발자용 도구(Node.js)가 있어야 설치할 수 있었지만, 지금은 윈도우 전용 설치 프로그램이 알아서 필요한 걸 다 챙겨줍니다.

화면 왼쪽 아래에 뜨는 메뉴에서 "Windows PowerShell"(또는 "터미널")을 클릭하세요

🔎 제대로 열렸는지 확인하는 법

파란 배경(또는 검은 배경)의 창이 뜨고 PS C:\Users\내이름> 처럼 앞에 PS가 붙어 있으면 PowerShell이 맞습니다. PS가 안 붙어 있으면 CMD라는 다른 창이니, 닫고 위 과정을 다시 해주세요.

2 설치 명령어 한 줄 붙여넣기

아래 명령어를 그대로 복사해서 PowerShell 창에 붙여넣고(우클릭 또는 Ctrl+V) Enter를 누르세요.

Windows PowerShell
—   □   ×
PS C:\Users\내이름> irm https://claude.ai/install.ps1 | iex
 
# 설치가 진행되는 동안 몇 줄의 진행 메시지가 나옵니다
Downloading Claude Code...
Installing... ████████████████████ 100%
✔ Claude Code installed successfully
PS C:\Users\내이름>
⚠️
설치 직후 "claude가 뭔지 모르겠다"는 오류가 나오면? 정상입니다. PowerShell 창을 완전히 닫고 1번 과정처럼 다시 열어주세요. 방금 설치된 프로그램의 위치를 새 창이 다시 인식하는 과정이에요.

📌 이 명령어는 뭘 하는 건가요?

irm은 인터넷에서 설치 파일을 내려받고, iex는 그걸 바로 실행하라는 뜻이에요. 즉 "인터넷에서 클로드 코드 설치 프로그램을 받아서 바로 설치해줘"라는 한 줄짜리 명령입니다. 클로드를 만든 회사(Anthropic)의 공식 설치 주소(claude.ai)에서 내려받기 때문에 안전합니다.

3 작업할 폴더로 이동하기클로드 코드는 "지금 열려 있는 폴더"를 기준으로 파일을 읽고 작업합니다. 원하는 프로젝트 폴더로 먼저 이동해야 해요.

📁 cd 명령어 — 폴더 이동하기

cd는 "change directory(폴더 바꾸기)"의 줄임말이에요. cd 뒤에 이동하고 싶은 폴더 경로를 적어주면 됩니다.

Windows PowerShell
—   □   ×
# 예시 1) 문서 폴더 안의 "MyProject" 폴더로 이동
PS C:\Users\내이름> cd C:\Users\내이름\Documents\MyProject
 
# 예시 2) 바탕화면으로 이동
PS C:\Users\내이름> cd $env:USERPROFILE\Desktop
 
# 지금 폴더 안에 어떤 파일/폴더가 있는지 보기
PS C:\Users\내이름\Desktop> ls
PS C:\Users\내이름\Desktop>
하고 싶은 것입력할 명령어
특정 경로로 바로 이동cd C:\Users\내이름\Documents\폴더이름
바탕화면으로 이동cd $env:USERPROFILE\Desktop
한 단계 위 폴더로 이동cd ..
지금 폴더의 파일 목록 보기ls
새 폴더 만들고 그 안으로 이동mkdir 새폴더 ; cd 새폴더
💬
경로를 직접 입력하기 번거롭다면, 파일 탐색기에서 원하는 폴더를 열어둔 뒤 주소창의 경로를 복사해서 cd "복사한경로" 형태로 붙여넣어도 됩니다. 경로에 띄어쓰기가 있으면 꼭 큰따옴표로 감싸주세요.

✅ 로그인 후에는?

브라우저에서 로그인이 끝나면 PowerShell 창으로 자동으로 돌아오면서 클로드 코드 화면이 나타납니다. 로그인 정보는 내 컴퓨터에 안전하게 저장되므로, 다음부터는 로그인 없이 바로 claude만 입력하면 됩니다.

💬 이제 뭘 하면 되나요?

화면에 커서가 깜빡이면 바로 궁금한 걸 한글로 입력하면 됩니다. 예: 이 폴더에 있는 파일들 정리해줘. 사용 가능한 기능이 궁금하면 /help를 입력해보세요.

5 자주 만나는 오류, 이렇게 해결하세요

이런 메시지가 떠요원인해결 방법
'claude' is not recognized 흔함 설치 직후라 창이 새 프로그램 위치를 아직 모름 PowerShell 창을 완전히 닫고 1번 과정처럼 다시 열기
'irm' is not recognized PowerShell이 아니라 CMD(검은 창)에서 실행함 창을 닫고 Win+X로 PowerShell을 다시 열어서 시도
설치 중 SSL/TLS 관련 오류 오래된 Windows 10 보안 설정 설치 전에 [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12 입력 후 재시도
이상한 < 기호 섞인 에러 / 웹페이지 내용이 출력됨 일시적인 네트워크·지역 접속 문제 같은 명령어 재시도. 계속되면 winget install Anthropic.ClaudeCode로 설치 시도
화면에 6자리 코드만 뜨고 브라우저가 안 열림 원격/특수 환경에서 자동 연동이 안 되는 경우 표시된 코드를 그대로 복사해 터미널에 붙여넣기
⚠️
창을 껐다 켜도 'claude' is not recognized가 계속 뜬다면? 설치는 됐는데 윈도우가 claude 프로그램의 위치를 못 찾는 경우입니다. 아래 3단계로 직접 경로를 등록해주세요.

① 설치가 정말 되어있는지 확인하기

파일 탐색기 주소창에 아래 경로를 붙여넣고 Enter를 누르세요. 사용자명 자리에는 본인 윈도우 로그인 계정명을 넣습니다.

C:\Users\사용자명\.local\bin\

이 폴더 안에 claude.exe 파일이 보이면 설치는 정상적으로 된 것입니다. (파일이 없다면 2번 과정의 설치 명령어부터 다시 진행해주세요.)

② PowerShell에서 경로(PATH) 직접 등록하기

PowerShell을 열고 아래 3줄을 순서대로 붙여넣어 실행하세요. 첫 줄의 esther 부분만 위 ①에서 확인한 본인 사용자명으로 바꿔주세요.

Windows PowerShell
—   □   ×
# "esther" 자리를 본인 사용자명으로 바꿔서 입력
PS C:\Users\내이름> $folder = "C:\Users\사용자명\.local\bin"
PS C:\Users\내이름> $old = [Environment]::GetEnvironmentVariable("Path", "User")
PS C:\Users\내이름> [Environment]::SetEnvironmentVariable("Path", "$old;$folder", "User")
PS C:\Users\내이름>

📌 이 명령어는 뭘 하는 건가요?

윈도우는 claude라고 입력했을 때 어느 폴더를 뒤져볼지 "Path"라는 목록으로 관리합니다. 이 3줄은 "①에서 확인한 .local\bin 폴더도 그 목록에 추가해줘"라는 뜻이에요. claude.exe가 그 폴더 안에 있으니, 목록에 추가되면 윈도우가 어디서든 찾을 수 있게 됩니다.

③ PowerShell 완전히 재시작하기

명령어 실행 후, 열려 있는 PowerShell 창을 모두 닫아주세요. 주의 창 하나만 닫고 다시 여는 게 아니라, 떠 있는 PowerShell 창을 전부 닫아야 방금 등록한 경로가 새로 적용됩니다. 그 다음 1번 과정처럼 PowerShell을 새로 열고 claude를 입력해보세요.

  • 2

✓ 결론

윈도우에 개발 도구가 하나도 없어도 괜찮습니다. PowerShell을 열고, 설치 명령어 한 줄을 붙여넣고, 원하는 폴더로 이동한 뒤 claude라고 치고 로그인만 하면 준비 끝입니다. 전체 과정은 5분이면 충분합니다.
